# Vendas Estaduais
Base de migração derivada da Direção Geral.
Repositório e domínio devem permanecer independentes.
Dados compartilhados usam o Supabase canônico e RLS.
Vendedor comum: próprios pedidos/vendas/clientes/CRM/financeiro e concessões explícitas.
Sem fornecedores, investimentos, compras administrativas, membros/administração ou governança.
Realtime preparado para os dados operacionais compartilhados.
